# 🏛️ DEMOCRACIA S.A. — El Juego del Poder Real

> *"No cambié el mundo. Compré los que lo cambian."*

**Democracia S.A.** es un juego incremental (tipo Cookie Clicker) de temática político-satírica con sabor argentino. El jugador asume el rol de un operador político en las sombras cuyo objetivo es acumular influencia, corromper instituciones y, eventualmente, convertirse en dueño del sistema democrático.

---

## 🎮 Premisa

*"En la democracia real, los votos no se ganan, se compran. Y vos empezás con presupuesto cero."*

Sos un operador político en las sombras. No sos el candidato, no sos el votante — sos **la máquina que mueve las piezas**. Tu objetivo: pasar de operador independiente a **dueño del sistema entero**.

---

## 🎯 Mecánicas del Juego

### Recursos

| Recurso | Cómo se obtiene |
|---------|----------------|
| **Influencia** | Clic principal + generadores pasivos. Es tu recurso principal. |
| **Dinero** | Se genera pasivamente a partir de influencia (conversión). Necesario para operaciones avanzadas. |

La tríada: **más influencia → más dinero → más poder → más influencia**

### Compra múltiple
Los generadores se pueden comprar de a **x1**, **x10** o **Max** (la mayor cantidad que el jugador pueda pagar). El costo se calcula usando series geométricas.

## ⭐ Operaciones Especiales (Upgrades)

Los upgrades son mejoras permanentes que se compran una sola vez. Se desbloquean al cumplir ciertas condiciones (sin spoilers en la UI). Se dividen en categorías:

### Upgrades de Clic
Incrementan la influencia obtenida por cada clic:
- 📞 **El Llamado al Padrino** (+1/clic)
- 📱 **El Grupo de WhatsApp** (+2/clic)
- 🎥 **El Live de Instagram** (+5/clic)
- 💻 **La Militancia Digital** (+20/clic)
- 📜 **El DNU Infinito** (+100/clic)

### Upgrades de Generador (×2 multiplicador)
Cada generador tiene un upgrade asociado que **duplica** su producción. Se desbloquean al tener 10 unidades de ese generador:
- 👥 **La Cuadrilla Completa** → x2 Punteros
- 💵 **Contado con Liqui** → x2 Canjes
- 📋 **El Plan Jefazo** → x2 Ollas
- 📊 **Compra de Encuestadoras** → x2 Fundaciones
- 🎙️ **El 678 24/7** → x2 Focus Groups
- 📩 **La Licitación con Sobre** → x2 Empresarios
- 🖨️ **Imprenta propia** → x2 Pautas
- 💎 **La Jubilación de Privilegio** → x2 Reelecciones
- ✍️ **La Reforma Constitucional** → x2 Casta

### Upgrades de Dinero Pasivo
Aumentan la tasa de conversión influencia→dinero:
- 🏦 **El Cepo Selectivo** (+10%)
- 📉 **La Devaluación Amiga** (+25%)
- ✈️ **La Fuga Elegante** (+50%)

## 🎨 Diseño Visual

### Paleta General
- **Background**: Gradient celeste/cyan (#0ea5e9) → azul (#0369a1) → azul oscuro (#1e3a5f)
- **Cards**: Glassmorphism blanco (backdrop-blur 12px) con borde dorado (#d4af37/30)
- **Header/Footer**: Glass oscuro (rgba(0,0,0,0.6) + blur 12px)
- **Rotativo**: Negro semitransparente (rgba(0,0,0,0.4) + blur 12px)
- **Toasts/Modals**: Fondo negro con gradiente + borde dorado + líneas accent doradas
- **Texto**: Blanco puro (#ffffff) para foreground, gris claro (#cbd5e1) para muted

### Estética
- Tema argentino satírico sin tomar partido político
- Emojis como iconografía de generadores y upgrades
- Quotes satíricos en cada generador
- Labels uppercase con tracking en estilo "documento clasificado"
- Scrollbar personalizado con tinte dorado

### Métrica Satírica: "Calidad Democrática"
Un indicador que va de 100% a 0% a medida que el jugador acumula influencia. Frases que cambian según el nivel:
- 90%: *"La democracia funciona... más o menos."*
- 60%: *"Las leyes se parecen mucho a las propuestas de ciertos think tanks."*
- 30%: *"La oposición existe, pero recibe el mismo financiamiento."*
- 0%: *"No cambiaste el mundo. Compraste los que lo cambian."*

## 🏗️ Arquitectura Técnica

### Stack
- **Framework**: Next.js 16 (App Router) con TypeScript
- **Estilos**: Tailwind CSS 4 + shadcn/ui
- **Estado**: Zustand (client state management)
- **Persistencia**: localStorage + Supabase (cloud save)
- **Auth**: Supabase Auth (email + Google OAuth)
- **Animaciones**: Framer Motion
- **Hosting**: Cloudflare Pages

### Estructura de Archivos
```
src/
├── lib/game/
│   ├── types.ts          # Tipos del juego (GamePhase, configs, state)
│   ├── config.ts         # Datos: generadores, upgrades, milestones, fases
│   ├── calculator.ts     # Cálculos: costos bulk, producción, fases
│   ├── formatters.ts     # Formato de números y textos
│   ├── news.ts           # Rotativo de noticias (~53 headlines)
│   ├── save.ts           # Persistencia localStorage
│   ├── cloud-save.ts     # Guardado/carga en Supabase
│   └── supabase.ts       # Configuración del cliente Supabase
├── store/
│   ├── game-store.ts     # Zustand store central (estado del juego)
│   └── auth-store.ts     # Zustand store de autenticación
├── hooks/
│   └── use-game-loop.ts  # Game loop (tick 10/s, auto-save cada 30s)
├── components/game/
│   ├── GameHeader.tsx     # Barra superior: recursos, fase, auth
│   ├── InfluenceClicker.tsx # Botón principal de clic con floats
│   ├── GeneratorPanel.tsx  # Panel de generadores con x1/x10/Max
│   ├── UpgradesPanel.tsx   # Panel de operaciones especiales
│   ├── StatsPanel.tsx      # Stats + Calidad Democrática + Logros
│   ├── NewsTicker.tsx      # Rotativo de noticias
│   ├── AchievementToast.tsx # Toasts de logros desbloqueados
│   ├── GuideDialog.tsx     # Modal de guía rápida
│   └── AuthDialog.tsx      # Modal de login/registro
├── components/ui/          # Componentes shadcn/ui
└── app/
    ├── page.tsx           # Página principal del juego
    ├── layout.tsx         # Layout con metadata
    └── globals.css        # Estilos globales (tema, variables CSS)
```

### Mecánicas Técnicas
- **Game loop**: 10 ticks por segundo (100ms interval)
- **Auto-save**: cada 30 segundos + al cerrar pestaña
- **Offline progress**: al volver se calcula la producción acumulada (máx 24h)
- **Cost scaling**: `costo = baseCost × 1.15^unidades_compradas`
- **Bulk purchase**: costo por serie geométrica, max buyable por búsqueda binaria
- **Cloud save**: save/load en Supabase para usuarios autenticados
- **Auth**: email/password + Google OAuth vía Supabase
