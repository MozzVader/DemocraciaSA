🎨 Regla N° 5: Tailwind CSS = las clases largas

Ese "alphabet soup" como className="text-lg font-bold..." es Tailwind CSS. Cada clase es un estilo:

text-lg → font-size grande
font-bold → negrita
uppercase → mayusculas
px-4 py-3 → padding horizontal 4, vertical 3
border-b → borde inferior
opacity-60 → 60% de opacidad
hover:bg-[#d4af37]/5 → fondo dorado 5% al hover
md:grid-cols-[280px_1fr_300px] → grid 3 columnas desktop
animate-ping → animacion de ping/pulso

🛠 Flujo de trabajo recomendado para editar algo
  1. Veo algo en el navegador que quiero cambiar (ej: el texto de un boton, un color, un tamanio).
  2. Inspecciono el elemento con click derecho → "Inspeccionar elemento". Veo el HTML renderizado y las clases CSS aplicadas.
  3. Busco un texto unico de ese elemento con Ctrl+Shift+F en VS Code. Busco algo que solo aparezca en ese componente.
  4. Llego al archivo correcto y edito lo que necesite.
  5. El navegador se actualiza solo con hot reload. No hace falta refrescar manualmente.
🎯 Ejemplos practicos de busqueda

Cambiar el tamanio del boton de influenciar → busco INFLUENCIAR → me lleva a InfluenceClicker.tsx

Cambiar el color del progreso de democracia → busco --progress-color → StatsPanel.tsx y globals.css

Agregar un nuevo generador → voy a config.ts y agrego una entrada al array GENERATORS

Cambiar cada cuanto guarda el autosave → busco AUTOSAVE o setInterval → use-game-loop.ts

Modificar el dialogo de login → busco Acceso Clasificado o Correo → AuthDialog.tsx

Cambiar la duracion del toast de logro → busco 5000 o duration → AchievementToast.tsx

💬 Conceptos clave de React

Componente: Un archivo .tsx que retorna JSX (HTML-like). Cada componente es independiente y reutilizable.

Props: Parametros que un componente padre le pasa a un hijo. Ej: <AuthDialog open={true} />

Store (Zustand): Estado global. Cualquier componente puede leer/escribir con useGameStore(). Cambia el store → se re-renderiza todo lo que lo use.

useEffect: Codigo que se ejecuta cuando algo cambia. Se usa para inicializar, reaccionar a cambios, y limpiar recursos.

🎯 Si en algun momento te trabas, decime "quiero cambiar X" y te digo exactamente en que archivo y linea ir. Con esta guia y Ctrl+Shift+F buscando texto visible, vas a encontrar el 90% de las cosas por tu cuenta.
