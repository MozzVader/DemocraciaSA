Como Se Juega
"Todo lo que necesitas saber para conquistar el sistema."
🗳️
Influenciar
Clickea el boton central para ganar influencia. A medida que compres mejoras, cada clic rendira mas.
🚀
Red de Influencia
Los generadores producen influencia automaticamente por segundo. Cada uno es mas caro pero genera mas.
⭐
Operaciones Especiales
Son mejoras unicas que se desbloquean al cumplir ciertas condiciones de influencia o generadores.
🏆
Logros
Se desbloquean automaticamente a medida que acumulas influencia total. Cada logro otorga bonificaciones permanentes.
📰
El Rotativo
Son noticias satiricas que cambian solas. No afectan el juego, pero mantienen el morale alto.
📊
Las Fases
El juego tiene 3 fases: Municipal, Provincial/Nacional e Imperio. Cada fase habilita nuevos generadores mas poderosos.
