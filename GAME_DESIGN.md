# 🏛️ DEMOCRACIA S.A. — El Juego del Poder Real

> *"No cambié el mundo. Compré los que lo cambian."*

**Democracia S.A.** es un juego incremental (tipo Cookie Clicker) de temática político-económica con humor negro satírico. El jugador asume el rol de un operador político en las sombras cuyo objetivo es acumular influencia, corromper instituciones y, eventualmente, convertirse en dueño del sistema democrático.

---

## 🎮 Premisa

*"En la democracia real, los votos no se ganan, se compran. Y vos empezás con presupuesto cero."*

Sos un operador político en las sombras. No sos el candidato, no sos el votante — sos **la máquina que mueve las piezas**. Tu objetivo: pasar de operador independiente a **dueño del sistema entero**.

---

## 🎯 Mecánicas del Juego

### Recursos

| Recurso | Cómo se obtiene |
|---------|----------------|
| **Influencia** 🎯 | Clic principal + generadores pasivos. Es tu recurso principal. |
| **Dinero** 💰 | Se genera pasivamente a partir de influencia (conversión). Necesario para upgrades avanzados. |
| **Capital Político** 🏆 | Se obtiene al desbloquear milestones. Indica tu nivel de control del sistema. |

La tríada: **más influencia → más dinero → más poder → más influencia**

## ⭐ Operaciones Especiales (Upgrades)

Los upgrades son mejoras permanentes que se compran una sola vez. Se dividen en categorías:

### Upgrades de Clic
Incrementan la influencia obtenida por cada clic:
- **Llamaradas Estratégicas** (+1/clic) — 100 influencia
- **Blackberry Diplomático** (+2/clic) — 1,000 influencia
- **Acceso al Salón Privado** (+5/clic) — 10,000 influencia
- **La Firma del Operador** (+20/clic) — $100,000 dinero
- **El Warranty Eterno** (+100/clic) — $10,000,000 dinero

### Upgrades de Generador (×2 multiplicador)
Cada generador tiene un upgrade asociado que **duplica** su producción. Se desbloquean al tener 10 unidades de ese generador.

### Upgrades de Dinero Pasivo
Aumentan la tasa de conversión influencia→dinero:
- **Cuenta Suiza Básica** (+10%) — 2,000 influencia
- **Fondo de Inversiones** (+25%) — 500,000 influencia
- **Holding Offshore** (+50%) — $50,000,000 dinero

### Estética General
- **Dark theme** por defecto (como un documento clasificado)
- Tipografía serif elegante para headings, mono para números
- Cards con borde dorado sutil en hover
- Textos entre comillas con eufemismos satíricos
- Footer con sello "DOCUMENTO CLASIFICADO"

### Métrica Satírica: "Calidad Democrática"
Un indicador que va de 100% a 0% a medida que el jugador acumula influencia. Frases que cambian según el nivel:
- 90%: *"La democracia funciona... más o menos."*
- 60%: *"Las leyes se parecen mucho a las propuestas de ciertos think tanks."*
- 30%: *"La oposición existe, pero recibe el mismo financiamiento."*
- 0%: *"No cambiaste el mundo. Compraste los que lo cambian."*

## 🏗️ Arquitectura Técnica

### Stack
- **Framework**: Next.js 16 (App Router) con TypeScript
- **Estilos**: Tailwind CSS 4 + shadcn/ui
- **Estado**: Zustand (client state management)
- **Persistencia**: localStorage (actualmente), Supabase (futuro)
- **Animaciones**: Framer Motion
- **Hosting**: Cloudflare Pages
- **Base de Datos**: Supabase (PostgreSQL, auth anónima) — pendiente de integración

### Estructura de Archivos
```
src/
├── lib/game/
│   ├── types.ts          # Tipos del juego
│   ├── config.ts         # Datos (generadores, upgrades, milestones)
│   ├── calculator.ts     # Cálculos (costos, producción)
│   ├── formatters.ts     # Formato de números y textos
│   └── save.ts           # Persistencia localStorage
├── store/
│   └── game-store.ts     # Zustand store central
├── hooks/
│   └── use-game-loop.ts  # Game loop (tick, auto-save)
├── components/game/
│   ├── GameHeader.tsx     # Barra superior con recursos
│   ├── InfluenceClicker.tsx # Botón principal de clic
│   ├── GeneratorPanel.tsx  # Panel de generadores
│   ├── UpgradesPanel.tsx   # Panel de upgrades
│   └── StatsPanel.tsx      # Stats + Calidad Democrática + Milestones
└── app/
    ├── page.tsx           # Página principal del juego
    ├── layout.tsx         # Layout con metadata
    └── globals.css        # Estilos globales (tema político)
```

### Mecánicas Técnicas
- **Game loop**: 10 ticks por segundo (100ms interval)
- **Auto-save**: cada 30 segundos + al cerrar pestaña
- **Offline progress**: al volver se calcula la producción acumulada (máx 24h)
- **Cost scaling**: `costo = baseCost × 1.15^unidades_compradas`
